# Hermes Google-Integration

Statische Informationsseite für den Google-OAuth-Zustimmungsbildschirm von Hermes.

## GitHub Pages

Nach dem Aktivieren von GitHub Pages wird die Seite zunächst unter
`https://mrvnbttchr.github.io/hermes-google-oauth/` veröffentlicht.

Für die spätere Custom Domain `hermes.mrvnbttchr.de` ist ein CNAME-DNS-Eintrag
bei Hostinger erforderlich. Erst nach DNS-Validierung in GitHub Pages soll eine
`CNAME`-Datei mit diesem Hostnamen ergänzt werden.
